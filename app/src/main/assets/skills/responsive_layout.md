# 📱 Skill: Adaptabilidad & Responsive Design

## Principios Responsive
- **Estrategia Mobile-First**: Estructura la UI primero para dispositivos móviles y escala fluidamente hacia pantallas más grandes.
- **Flexbox & Grid**: Utiliza `display: flex; flex-wrap: wrap;` y `grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));`.
- **Cero Desbordamiento Horizontal**: Garantiza `max-width: 100%` u `overflow-x: hidden` para evitar barras de desplazamiento horizontales molestas.
- **Media Queries & Unidades Relativas**: Aplica `@media (max-width: 768px)`, `vw`, `vh`, y `clamp()` para tipografías adaptativas.
- **Áreas Táctiles Cómodas**: Asegura un área mínima de toque de 48px para botones y elementos interactivos.
